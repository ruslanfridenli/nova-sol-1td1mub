# Nova Sol — Neon Runner

A neon snake runner on a 20×20 grid at 12 ticks/s with wrap-around walls. Keyboard, touch and score persistence included.

## Features

- 20×20 grid gameplay
- Variable speed and wrap-around mode
- 0 obstacles for extra challenge
- Keyboard (arrows/WASD) and touch swipe controls
- Persistent best score via localStorage
- English/German interface

## Local development

```bash
git clone https://github.com/ruslanfridenli/nova-sol-1td1mub.git
cd nova-sol-1td1mub
# open index.html in a browser, or serve statically:
npx serve .
```

No build step, no dependencies — pure static site.
